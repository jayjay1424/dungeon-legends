# Software Architect Skill

## Directives
- Design non-destructive, idempotent database migrations with appropriate indexes and constraints.
- Separate game logic, state management, audio, and UI into decoupled, testable modules.
- Formulate clear API contracts and data models shared between client components and backend routes.
- Balance performance and maintainability, ensuring low bundle sizes and fast time-to-interactive.
- Plan scalable multiplayer and realtime channel subscriptions to avoid unnecessary database polling.
