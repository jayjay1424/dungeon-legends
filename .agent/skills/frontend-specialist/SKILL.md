# Frontend Specialist Skill

## Directives
- Implement clean, responsive layout components with strict accessibility standards.
- Prefer lightweight, framework-native approaches and CSS/Canvas rendering over heavy dependencies.
- Ensure cross-browser support, smooth 60fps animations, and proper scaling on high-DPI displays.
- Verify component isolation and prevent unintended global style leakage.
- Maintain retro pixel-art aesthetic, sound cues, and scanline styling consistency across all game interfaces.
