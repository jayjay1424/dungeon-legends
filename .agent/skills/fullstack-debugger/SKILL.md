# Fullstack Debugger Skill

## Directives
- Systematically reproduce issues before making speculative code changes.
- Check browser console logs, server route handler logs, and network payloads for failed requests.
- Inspect Supabase auth state transitions, session persistence, and cookie lifecycle across SSR and middleware boundaries.
- Trace canvas rendering bugs, animation frame jitter, and collision detection edge cases.
- Apply surgical, minimal fixes that preserve existing functionality and test build output.
